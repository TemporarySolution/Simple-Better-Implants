# Simple-Better-Implants
A mod created and published in [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3802560036) for a game named ["Caves of Qud"](https://store.steampowered.com/app/333640/Caves_of_Qud/).

This mod creates second-tier versions of the stat implants and adds them to the game world.

## Workshop description:

Have you ever found it odd that many implants have upgraded versions, yet the basic stat-boosting implants — which practically beg for them — do not? Perhaps standard bionic arms and legs just aren't enough for your cyborg assassin anymore? Or maybe you simply want to see more variety in "chrome" that stays true to the game's aesthetic? If so, this mod is for you!

Simple Better Implants adds second tier of in game stat-implants to buy and found in caves of Qud.

List of new implants:

- Advanced Bionic Hands (Agility)
- Advanced Bionic Arm (Strength)
- Advanced Bionic Heart (Toughness)
- Advanced Dopamine Synth (Willpower)
- Pristine Visage (Ego)

All implants have 9 LP cost, and +6 to respective stat. All added to High-tier cybernetic pool so should be searched in respected areas.

## Installation

Subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3802560036), or copy the mod folder into your Caves of Qud `Mods` directory.
